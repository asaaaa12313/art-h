# 리서치: 진료과목 상세 강화 + 브로셔 콘텐츠 반영

> 작성일: 2026-06-15 / 작업 주제: 진료과목 상세 페이지를 브로셔 내용 기준으로 강화

## 1. 사용자 요구

1. 진료과목 각 세부사항을 클릭했을 때 "좀 더 자세히" 나오게
2. 첨부 브로셔(`아트에이치치과_브로셔.pdf`, 12쪽) 내용을 기준으로 제작
3. **확정 방향**: (Q1) 별도 상세 페이지 강화 / (Q2) 브로셔 강점 콘텐츠를 진료과목 안에 녹이기

## 2. 현재 코드 구조 (이미 구현된 것)

| 영역 | 파일 | 현황 |
|---|---|---|
| 콘텐츠 데이터 | `lib/copy.ts` → `TREATMENTS` | 7개 과목. 각: `en/ko/slug/d/summary/intro/processes[]/features[]/faqs[]` |
| 목록 페이지 | `app/treatments/page.tsx` | 7개 행, 클릭 시 `/treatments/[slug]`로 이동 (이미지+제목+설명+화살표) |
| 상세 페이지 | `app/treatments/[slug]/page.tsx` | **이미 존재**. 요약→소개→치료과정→차별점→FAQ→이전/다음 네비 |
| 홈 미리보기 | `app/home/Home.tsx` | 진료과목 3카드 (전체보기 링크) |
| 시설 페이지 | `app/facility/page.tsx` | 노바케어/HOCL/살균수 키워드 **없음** |

**즉, "클릭 시 상세"는 이미 동작한다.** 문제는 상세 내용이 일반적이고 브로셔의 차별화 포인트가 0건 반영이라는 점.

### 진료과목 7개 (현재)
임플란트 / 신경치료 / 사랑니 발치 / 턱관절치료 / 의식하진정 / 잇몸·스케일링 / 치아미백

### 기존 이미지 자산 (`public/media/images/`)
`cert, consult(2), doctor, equipment(3), exterior, powder(1), recovery(1), surgery(2), treatment-room(3), waiting, xray(2)`
- `xray/xray-01·02.jpg` → 상악동 거상술 X-RAY 후보
- `equipment/equipment-01~03.jpg` → 장비(노바케어/미백기기 후보)
- `powder/powder-01.jpg` → GBT 파우더 후보

## 3. 브로셔 콘텐츠 인벤토리 (12쪽)

| 쪽 | 제목 | 핵심 내용 |
|---|---|---|
| 1 | 정품 임플란트 스위스 SIC | **3대 기술력**: ①두꺼운 벽 두께(찢어짐 극소화) ②쉽게 안 풀리는 잠금(어버트먼트 토크 20Ncm vs 일반 30Ncm) ③감염 위험 축소(순수 티타늄+SICmatrix, 기저질환자 대응). 스위스 기술·독일 제조 |
| 2 | 살균수 치과수관 관리 | 노바케어(NOVACARE) 시스템, 전기분해수(HOCL) 도입 |
| 3 | What is HOCL | 차아염소산수 = 대장균·살모넬라·콜레라·진균·바이러스·사상균·아포균 살균, **5분 내 아포균 완전 사멸** |
| 4 | 미백 시스템 | **기기 3종**: GBT Machine(미백 전 치면세정·파우더/초슬림팁), Endo-Wiz(시린 증상 완화), Osstem Vutees light(미백광·미백제 활성화) ※브로셔 3번째 제목은 오타(실제 Vutees) |
| 5 | 원장 인사말 | 협진/자연치아보존/소통/공간배려 (이미 about·greeting에 반영됨) |
| 6 | 로고 | — |
| 7 | 빌딩(IBS TOWER 송도) | exterior 자산 있음 |
| 8 | 의료진 2인 | 구강악안면외과(임플란트·턱관절·사랑니) / 치과보존과(신경·충치·미백) — doctor 반영됨 |
| 9 | 편안한 공간 | 데스크·대기실·프라이빗룸 (facility 반영됨) |
| 10 | 무통증 GBT | 시리지 않은 잇몸 관리. **대상 3종**: 스케일링이 아파 미룬 분/잇몸 자주 붓고 피나는 분/착색으로 누렇게 보이는 분 |
| 11 | 수술 정교·의식하 진정 | 정교한 수술 + 수면(의식하진정) (sedation 반영됨) |
| 12 | 고난이도 임플란트 | **상악동 거상술 BEFORE/AFTER X-RAY**. 어려운 치조골에서도 전문의 식립 |

## 5. 기술 스택 / 제약

- Next.js 16 + React 19, App Router, 서버 컴포넌트 위주
- 스타일: 인라인 `<style>` + CSS 변수(`--c-navy`, `--c-warm`, `--f-display` 등) + `Reveal` 등장 애니
- 데이터-뷰 분리: `lib/copy.ts`(콘텐츠) ↔ `app/treatments/[slug]/page.tsx`(렌더)
- 8GB 맥 → 로컬 풀빌드 자제, `tsc --noEmit`로 1차 검증

## 6. 핵심 설계 판단

1. `TREATMENTS` 항목에 **선택적(optional) 확장 블록** 추가 → 있는 과목만 상세에서 렌더 (기존 7개 구조 깨지 않음)
2. 확장 블록 종류(브로셔 콘텐츠 형태에 맞춤):
   - `tech[]`: 번호+제목+수치+설명+대상 (SIC 3대 기술)
   - `devices[]`: 이름+역할+설명(+이미지) (미백 기기 3종)
   - `beforeAfter`: 전/후 이미지 + 캡션 (상악동 거상술)
   - `targets[]`: 대상 환자 칩 (무통증 GBT)
3. 이미지: 기존 자산 우선, 부족 시 브로셔 PDF에서 추출(`pdfimages`/페이지 렌더)
4. 노바케어는 진료과목 아님 → `facility` 페이지 섹션으로
