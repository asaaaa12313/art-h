## 현재 우리 사이트와의 격차

우리 상세 페이지([app/treatments/[slug]/page.tsx](../app/treatments/%5Bslug%5D/page.tsx))는 이미 요약·쇼케이스(SIC/오스템)·기술력 3종·상악동 모식도·치료과정(텍스트)·차별점·FAQ를 갖춤. 부족한 것만 추가하면 된다.

| 하늘리더스에 있고 우리에 없는 것 | 대상 과목 |
|---|---|
| **치료 종류 소개** (임플란트 종류가 다양하다는 업체 언급 반영) | 임플란트 |
| **단계별 모식도 그림** (현재 텍스트만) | 임플란트·사랑니·신경치료 |
| **보험 임플란트 안내** (만 65세, 평생 2개) | 임플란트 |
| **시술 후 주의사항 01~06** | 임플란트·사랑니·신경치료 |
| **대상 체크리스트** (✓ 이런 분께) | 사랑니·신경치료 |
| 치료 전후 실사진 슬라이더 | ❌ 제외 — 촬영본 없음 + 전후사진은 의료광고 심의 대상(리스크). 모식도로 대체 |

## 기각한 대안

- **전면 리뉴얼(메뉴·디자인 재설계)**: 기각 — 업체가 "하나씩이라도"라고 명시했고, 현 디자인 시스템(v1.45)이 이미 하늘리더스보다 상위 품질. 콘텐츠 깊이만 보강이 정답.
- **모식도 = AI 이미지 생성**: 기각 — 의학 모식도는 정확도 오류 리스크 + 스타일 불균일. (승인 시 B안으로 선택 가능)
- **모식도 = 타 사이트 이미지 재사용**: 기각 — 저작권 침해. 하늘리더스에서 가져오는 건 구조·구성 아이디어까지만.

## 단계별 계획

### 1차 — 임플란트 (승인 시 바로 착수)
1. **임플란트 치료 종류** 섹션 신설 — 카드 + 소형 모식도: 디지털 가이드 / 뼈이식 / 상악동 거상(기존 승격) / 전체 임플란트(무치악) / 보험 임플란트
2. **치료 단계 6-스텝 모식도** — 기존 텍스트 과정에 단계별 SVG 그림 부착 (발치된 자리 → 식립 → 골유착 → 지대주 → 크라운)
3. **보험 임플란트 안내** — 표 4칸(적용대상·적용범위·본인부담률·주의사항). ⚠️ 아트에이치가 보험 임플란트 취급하는지 업체 확인 1건 필요
4. **수술 후 주의사항 6가지** 섹션 (공통 컴포넌트로 제작 → 2·3차 재사용)
5. FAQ 3개 → 6개 확장 (통증·성공률·부작용·연령 등 하늘리더스 질문 참고해 자체 답변 작성)

### 2차 — 사랑니 발치
- 발치 대상 체크리스트 ✓5 · **매복 유형 모식도**(수직/경사/수평 매복 3종 SVG) · 발치 후 주의사항 6 · FAQ 확장

### 3차 — 신경치료
- **충치 진행 4단계 단면 모식도**(법랑질→상아질→치수염→근관치료) · 치료 단계 모식도 · 치료 후 주의사항 · FAQ 확장

### 4차 (추후) — 나머지 과목 동일 패턴 + 촬영본 수급 시 실사 교체

## 승인 결과 (2026-07-20)
