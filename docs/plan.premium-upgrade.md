## 디자인 방향 — ✅ B안(화이트 경량화) 확정 (2026-06-25)

> 사용자 확정: **B안**. 배경 화이트 중심 + 네이비/골드는 CTA·강조 포인트 + 제목 일부 명조(세리프). A/C안은 미채택(기록만 보존).

### A안: 현 네이비+골드 유지, 밝게 보정 (보수·안전)
- 브랜드 일관성 유지, 작업량 적음. 모바일에서 어두운 인상만 완화(이미지 하이키, 여백 정리)
- 리스크: 하늘리더스의 "가볍고 깨끗한 화이트 프리미엄"과는 결 다름

### B안: 화이트 기반 경량화 + 네이비/골드는 포인트로 (하늘리더스 지향·추천)
- 배경 화이트 중심, 네이비·골드는 CTA·강조에만. 제목 일부 명조(세리프) 도입 → 격조
- 사용자 요청("하늘리더스 참조, 프리미엄")에 가장 부합
- 리스크: 변경 폭 큼(컬러·폰트 토큰 조정)

### C안: 하이브리드 — 화이트 섹션 + 다크(네이비) 강조 섹션 교차
- 밝은 콘텐츠 섹션 + 중간에 네이비 풀블리드 1~2개(영상/슬로건)로 리듬
- 프리미엄 호텔 사이트 느낌. 영상 강조에 유리

## 구현 Phase (승인 후 진행 · 작은 단위)

### Phase 0 — 히어로 포스터 폴백 🔴 긴급·독립
- [ ] `HeroVideo.tsx`: 영상 위에 `poster` 정지컷을 항상 깔고(`<img>` 베이스 레이어), 영상 `canplay` 시 페이드인. reduced-motion 아니어도 적용
- [ ] `HeroVideo.module.css`: poster 레이어 z-index/opacity 트랜지션
- 검증: 네트워크 느리게(throttle) 첫 화면에 사진 노출, 빈 네이비 0

### Phase 1 — 감성 인트로 시퀀스 (하늘리더스식, 우리 카피로)
- [ ] story 섹션 위/대체로 "환자 1인칭 감성 카피" 1~2블록 추가 (밝은 시설 사진 위 텍스트)
- [ ] 카피는 기존 PRD 지향 문장 활용 ("다시 가고 싶은 곳" 등), 표절 아닌 우리말로
- 검증: 스크롤 시 자연스러운 페이드, 모바일 가독성

### Phase 2 — 강점/진료 시스템 섹션 (신뢰 근거) ⭐ 밀도 핵심
- [ ] `SYSTEM_ITEMS`(9단계 멸균/독립수술실/원데이보철/치료보증제) 4카드 메인 노출
- [ ] 또는 `PROMISE_ITEMS`(전문의협진/자연치아보존/소통/공간배려) 중 택1 or 병합
- 검증: 4항목 카드 그리드, 모바일 1열

### Phase 3 — 진료과목 3 → 7 확장
- [ ] `TREATMENTS` 7개 전체를 메인 카드/슬라이드로 (큰 사진 + 한 줄 설명)
- [ ] 모바일: 2열 그리드 또는 가로 스크롤
- 검증: 7개 노출, 링크 정상

### Phase 4 — 의료진 경력 요약
- [ ] 최종원(구강악안면외과)·강지수(보존과) 사진 + 핵심 경력 3~4줄 + [의료진 더보기]
- [ ] "전문의 협진" 강조 (대학병원 출신 등)
- 검증: 2인 카드, 모바일 세로

### Phase 5 — 시설 영상 섹션 (사용자 요청) ✅ 소스 확인됨
- [ ] 드라이브 원본(드림에이지) 활용: 대기실·데스크·인테리어 + 송도 도시전경(주간) 드론영상. **가로(PC)/세로(모바일) 버전 모두 보유** → 반응형 최적
- [ ] 웹용 압축(1080p + 720p mp4, 음소거 루프) → `public/media/video` 추가 (다운로드는 사용자 확인 후)
- [ ] 주간 컷 위주 구성. **야간 뷰는 폴더에서 미확인** → 소스 받으면 추가, 없으면 주간만
- 검증: 영상 자동재생(muted/playsInline), 모바일 720p, 포스터 폴백

### Phase 6 — 프리미엄 톤 보정 (선택 디자인안 반영)
- [ ] 여백 리듬 정리(섹션 padding/min-height 축소 — 휑함 제거)
- [ ] 이미지 하이키 톤 통일, (B/C안 시) 화이트 기반·명조 제목
- 검증: 5축 자기점검(폰트/컬러/레이아웃/접근성/완전성)

### Phase 7 — 모바일 QA + 검수
- [ ] 360/390/414px 가독성, CTA 탭 영역 44px, 영상 데이터 절약(720p)
- [ ] 검수봇 6축 호출 → Critical/High 0까지 루프
- 검증: `tsc --noEmit` + eslint + Vercel READY

## 트레이드오프 / 고려사항
- **영상 다수 = 모바일 데이터·로딩 부담** → 720p 모바일 소스 + lazy + 포스터 우선. 시설 영상은 1~2개로 절제
- **콘텐츠 늘리면 길어짐** → "밀도"는 늘리되 섹션당 핵심만(하늘리더스도 한 화면 1메시지). 무한 스크롤 지양
- **명조 도입(B안)** = 브랜드 변화 → 사용자 확인 필수
- 주간/야간 뷰는 **소스 없음** → 구조만 만들고 촬영분 들어오면 교체(개원 후 사진 전략과 동일)
