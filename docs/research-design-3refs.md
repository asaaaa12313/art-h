# 리서치 — 경쟁 3사 디자인 분석 (2026-07-23)

> 사용자 제공 네이버 광고 랜딩 3곳을 브라우저 실측(스크린샷 + DOM/CSS 토큰 추출)으로 분석.
> 목적: 아트에이치 홈페이지를 "더 깔끔하고 이쁘게" 개편할 기획의 근거 수집.

| 항목 | 루센트치과 (홈) | 퍼펙트치과 (임플란트 랜딩) | 미니쉬치과병원 (라미네이트 랜딩) |
|---|---|---|---|

- 실측 방법: 각 사이트 브라우저 접속 후 스크린샷 + 전체 요소 computedStyle 집계(폰트·배경색 상위 빈도) + 섹션 innerText 인벤토리. 퍼펙트·미니쉬는 스크롤 연동 배경 교체 구조라 중간 섹션은 텍스트 인벤토리로 확보(✅확정), 비주얼 톤은 히어로 캡처 기준(추정 일부).

## 2. 3사 관통 공통 패턴 (우리에게 없는 것)

1. **상시 노출 전환 장치** — 3사 모두 화면 어디서든 전화·상담·예약이 한 클릭. 아트에이치는 헤더 "네이버 예약" 버튼 1개뿐(스크롤 내리면 헤더와 함께 존재감 약함).
2. **사회적 증거 숫자** — 리뷰 2,114건(루센트)·최대 10년 보증(미니쉬)·사례 수. 아트에이치 STATS는 시설 숫자(9단계 멸균·8층)라 "남들이 인정한 숫자"가 아님.
3. **한 섹션 = 한 메시지 풀블리드 스토리** — 장비·재료 실명 + "그래서 환자에게 뭐가 좋은지" 서사. 아트에이치는 과목 상세엔 있으나(v1.46~49) 홈에는 압축 노출이 없음.
4. **비교 프레임** — "일반적으로는 A, 우리는 B" 구도(미니쉬 보증 비교표가 대표).
5. **거대 타이포 연출** — 워터마크 영문(루센트) / 초대형 후킹 카피(미니쉬)로 시선 고정.

## 3. 아트에이치 현재와의 대조

| 관점 | 아트에이치 현황 | 격차 |
|---|---|---|
| 브랜드 톤 | 세리프 + 잉크 네이비 + 여백 — 3사보다 오히려 고급·차분 | 유지할 자산 (3사식 광고 톤으로 갈아엎으면 손해) |
| 전환 장치 | 헤더 네이버예약 1개 | **최대 격차** — 플로팅 상담 레일 부재 |
| 사회적 증거 | 없음 (리뷰·후기·보증 노출 0) | 리뷰 뱃지·치료 보증제 시각화 여지 (보증제 문구는 copy.ts SYSTEM_ITEMS에 이미 존재) |
| 홈 스토리 밀도 | 감성 문구 중심, 장비·전문의 근거는 과목 상세로 분산 | 홈에 "왜 아트에이치인가" 풀블리드 밴드 없음 |
| 실사 활용 | 07.21 촬영 실사 23장+영상 6개 확보(오늘 반영) | 홈 진료과목 카드가 아직 구형 시설 컷 일부 |

## 4. 주의(리스크)

- 3사 카피의 "압도적·초격차·완벽" 류 최상급은 의료광고 심의 위험 — 벤치마킹 대상은 **구조**이지 **문구**가 아님 (기존 v1.49 완화 톤 유지).
- 미니쉬식 타사 비방 비교("타 병원은 1~2년")는 비교 광고 규제 소지 — 우리는 "일반 원칙 vs 우리 약속" 구도로 순화 필요.
