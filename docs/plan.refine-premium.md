### 고급스러움을 만드는 8가지 공통 언어
1. **세리프 헤드라인 + 작은 영문 라벨**의 강한 크기 대비
2. **풀블리드 이미지/영상** + 그 위 텍스트·캡션 오버레이
3. **에디토리얼 텍스트 밀도** (여백은 많되, 텍스트 블록이 꽉 차 긴장감)
4. **숫자/통계 임팩트** (신뢰 지표)
5. **다크 ↔ 라이트 섹션 대비** 리듬
6. **얇은 골드 라인·구분선·섹션 번호** 디테일
7. **부드러운 스크롤·패럴랙스 모션**
8. **클로즈업 디테일 이미지** (질감·정밀함)

## 2. 현재(v1.36) 진단 — "왜 휑한가"

| # | 문제 | 고급화 처방 |
|---|------|-----------|
| 1 | 섹션 세로 padding 과대(`clamp 72~130px`) + 콘텐츠 사이 빈 공간 | 여백 리듬 재설계 — 무의미 여백↓, 텍스트가 여백을 "지배" |
| 2 | **숫자 임팩트 0개** (하늘리더스는 150평·9단계·전문의4) | "신뢰 지표" 숫자 섹션 신설 (카운터 모션) |
| 3 | 시설 영상이 작은 박스(16:8) | **풀블리드 시네마틱 영상** + 오버레이 카피 |
| 4 | 카드 단조(사진+텍스트), 깊이감 약함 | 캡션 라벨(\| 키워드 \|)·얇은 골드 라인·호버 디테일 |
| 5 | 히어로 첫 장면에 인사문구 없음(체어 장면에만) → 첫인상 휑 | 인사문구 **항상 노출** + 골드 라인 + 스크롤 유도 |
| 6 | 감성 카피가 1블록뿐 | 풀블리드 이미지 위 **1인칭 카피 시퀀스**(SOLA·하늘리더스식) |
| 7 | 타이포 위계 평범(명조 추가했으나 대비 약) | 헤드라인 더 크게/굵게, 영문 라벨 letter-spacing 강조 |
| 8 | 섹션 전환 = 배경색만 교차 | 풀블리드 이미지/영상 **인터럽트**로 시각 리듬 |

## 3. 디벨롭 Phase (승인 후 · 작은 단위)

### Phase 1 — 여백·타이포 리듬 재설계 🔴 핵심
- [ ] 섹션 padding 재조정(과대 여백↓), 헤드라인 크기·대비↑, 영문 라벨 강조
- [ ] 얇은 골드 구분선·섹션 번호(01·02) 디테일 추가
- 검증: 스크롤 시 빈 화면 구간 사라짐

### Phase 2 — 숫자 임팩트 섹션 신설 ⭐
- [ ] 신뢰 지표 4종(전문의 2인 협진 / 진료 7과목 / 9단계 멸균 / 송도 IBS 8층 등) + 카운터 모션
- [ ] 다크(네이비) 또는 라이트 — 섹션 대비 고려
- 검증: 숫자 카운트업, 모바일 2열

### Phase 3 — 풀블리드 시설 영상 시네마틱화
- [ ] 시설 라운지 영상을 **풀폭(100vw) 시네마틱** + 오버레이 카피("송도의 하늘과 맞닿은 공간")
- [ ] 스크롤 패럴랙스 살짝
- 검증: 풀블리드 재생, 모바일 720p

### Phase 4 — 감성 카피 시퀀스 (에디토리얼)
- [ ] 풀블리드 이미지 위 1인칭 카피 1~2블록(SOLA 캡션 라벨식 \| 키워드 \|)
- [ ] 기존 인트로 강화
- 검증: 가독성·모션

### Phase 5 — 카드·진료과목 디테일 레이어
- [ ] 진료 카드: 캡션 라벨·호버 줌·얇은 라인·번호. 약속/시스템 카드 깊이감
- [ ] 호버 마이크로 인터랙션 통일
- 검증: 호버 동작, 대비 AA 유지

### Phase 6 — 히어로 강화 (✅ 라운지 우선 확정)
- [ ] **첫 영상 = 밝은 라운지/인테리어**(facility-lounge 또는 hero-2)로 재배치 → 화사한 첫인상
- [ ] 인사문구 **항상 노출**(첫 장면부터) + 골드 라인 + 스크롤 인디케이터 강조
- 검증: 첫 화면 임팩트

### Phase 7 — 검수 + QA
- [ ] 디자인 6축 검수봇(미감/안티슬롭/접근성/반응형/성능/완전성)
- [ ] 타입체크 + 모바일 360/390/414

## 4. 트레이드오프 / 가드
- **에디토리얼 밀도 ↑ ≠ 빽빽하게 욱여넣기** — "긴장감 있는 여백"이 목표. 한 화면 1메시지 유지
- 풀블리드 영상 = 데이터↑ → 720p·lazy·poster 우선
