## 0. 한 줄 결론

**재료(콘텐츠)는 냉장고에 가득 찼는데, 식탁(메인 페이지)엔 반찬 몇 개만 올라가 있다.** 진료 7과목·의료진 경력·진료시스템 4가지·강점 4가지가 `copy.ts`에 이미 다 있는데, 홈은 6개 섹션만 쓰고 대부분 안 꺼낸다. 게다가 첫 화면 영상이 안 떠서 텅 빈 네이비로 시작 → "단순하고 빈약하다"는 인상의 직접 원인.

## 2. 핵심 진단 (왜 모바일에서 빈약해 보이나) — 5가지

| # | 문제 | 근거 | 심각도 |
|---|------|------|--------|
| 1 | **첫 화면이 텅 빈 네이비** | 히어로 영상 로딩 전/실패 시 poster 폴백 없음(`HeroVideo.tsx`는 reduced-motion일 때만 poster). 실측: 데스크탑에서 8초+ 빈 화면. 모바일 셀룰러면 더 심각 | 🔴 치명 |
| 2 | **섹션당 콘텐츠 1개 + 거대 여백** | story=한단락, doctor=2줄. 섹션 padding `clamp(80~170px)` + min-height 큼 → 스크롤은 긴데 알맹이 없음 | 🔴 높음 |
| 3 | **진료과목 3개만 노출** | 보유 7개인데 메인 카드 3개 | 🟡 중간 |
| 4 | **강점·신뢰 콘텐츠 전무** | 9단계 멸균·전문의 경력·진료시스템·약속 등 "프리미엄 근거"가 메인에 0개 | 🔴 높음 |
| 5 | **시설 영상 미활용** | 사용자 요청(데스크·대기실 영상, 주야간뷰)인데 시설 섹션은 사진 3장뿐 | 🟡 중간 |

## 3. 하늘리더스치과 벤치마크

### 3.1 메인 구조 (스크롤 순서) — 콘텐츠가 빽빽
1. 히어로(밝은 대기실 사진 풀스크린) + "치과의 본질은 치료입니다. 하지만 그 이상을 고민합니다."
2. **감성 카피 시퀀스** (밝은 사진 위 옅은 블루 텍스트, 스크롤 연출): "치과는 항상 꺼려졌는데… 이제는 마음 편하게" → "하루가 맑아졌어요" → "가까운 사람에게 밝게 웃을 수 있어요" → "치료를 넘어 당신의 삶을 봅니다"
3. 브랜드 선언 + [자세히 알아보기]
4. **특별함 3가지** (01 진료시스템 / 02 자체기공소·원데이보철 / 03 전문의 협진)
5. 의료진 — 전문의 4인 협진(탭 전환)
6. 진료과목 **7개** (가로 슬라이드, 큰 사진 카드)
7. 특별함01 상세(9단계 멸균/독립수술실/당일보철/보증제 — 4항목)
8. 150평 규모 공간 강조
9. 자체기공소 1-DAY CEREC + 수상 기공사
10. 전문의 협진 상세
11. 핵심 장비 4종 (CEREC/플라즈마/페리오메이트/에어플로우)
12. 오시는 길(네이버맵)

### 3.2 무드 (고급스러움의 정체)
| 요소 | 하늘리더스 | 우리 현재 |
|------|-----------|----------|
| 컬러 | 화이트 + 매우 옅은 블루, 골드 거의 안 씀 → 가볍고 깨끗 | 네이비+골드 → 무겁고 클래식(나쁘진 않으나 모바일서 어두움) |
| 사진 | 매우 밝게 보정(화사·하이키), 인물 미소 중심 | 실사 양호하나 톤 통일 약함 |
| 제목 폰트 | 한글 명조(세리프) → 격조 | Pretendard(고딕) |
| 콘텐츠 밀도 | 12블록, 신뢰요소 가득 | 6블록, 신뢰요소 거의 없음 |
| 카피 | 환자 1인칭 감성 시퀀스 | story 1단락 |

### 3.3 중요 사실
- 하늘리더스는 **아임웹(imweb) 템플릿** 기반. 우리는 커스텀 코드 → **우리가 더 정교한 연출·성능·반응형 가능**(강점).
- 우리 대표원장(최종원)이 **하늘리더스치과 부원장 출신** (copy.ts 경력). 진료 구성이 비슷한 이유.

## 4. 영상 활용 (사용자 요청 핵심)

- 사용자 요청: ①데스크·대기실 인테리어를 사진+**영상**으로 ②**주간/야간 뷰** ③네이버 클립(드림에이지) 같은 고급 톤
- 네이버 클립(`tv.naver.com/h/101642493`)은 **다운로드(yt-dlp 미지원) + 브라우저(안전 차단) 모두 막혀** 직접 분석 불가 → 사용자 설명 + 보유 hero 영상으로 톤 추정
- 현재 보유 영상으로 **시설/대기실 영상 섹션 구성 가능**
- ✅ **드라이브 원본 확인** (드림에이지 촬영, `0.촬영본/드림)아트에이치치과`): 영상 폴더에 **가로(PC)/세로(모바일)** 버전 + 대기실·데스크·인테리어(드론 내부샷)·송도 도시전경·건물외관·진료·원장 영상 **다수**. 전부 주간. **야간 컷은 미확인.** 사진보정/사진ok컷 폴더에 최종 보정 사진도 있음
- 활용 방식: 웹용 압축(1080p/720p) 후 `public/media/video`에 추가 (다운로드는 사용자 확인 후)

## 5. 개선 방향 (요약 — 상세는 plan.premium-upgrade.md)

1. **히어로 포스터 폴백** — 영상 로딩 전/실패 시에도 화사한 정지컷 노출 (텅 빈 네이비 제거). 🔴 최우선
2. **메인 콘텐츠 밀도 ↑** — 이미 있는 자산을 메인으로 끌어올림: 감성 카피 시퀀스 / 강점(진료시스템 4) / 진료 7과목 / 의료진 경력 요약 / 시설 영상
3. **프리미엄 톤 보정** — 모바일에서 밝고 화사하게(하이키), 명조 제목 일부 도입 검토, 여백 리듬 정리(휑함 → 꽉 참)
4. **시설 영상 섹션** — 대기실·데스크 영상 + 주야간 뷰 슬롯
5. **모바일 우선** — 첫 1~2스크린에 "프리미엄 근거"가 바로 보이게 재배치
