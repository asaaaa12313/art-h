## C. 항목별 상세 근거

### 1. 렌더링 차단 — 판정 방식이 틀렸다

| 실측 (홈 `<head>`) | 값 |
|---|---|
| `<script>` 총수 | 11 |
| `async` 붙은 것 | 10 (`/_next/static/chunks/*.js`) |
| `noModule` | 1 — ES 모듈을 아는 브라우저(현행 전부)는 내려받지도 실행하지도 않음 |
| defer/async 없는 동기 스크립트 | **0** |
| `<link rel="stylesheet">` | 5 — 자체 CSS 3 + 외부 2 |

- 업계 기준(Lighthouse "렌더링 차단 리소스" 규칙)은 **defer/async 없는 스크립트**와 **media 조건 없는 스타일시트**만 센다. 이 기준으로 우리 사이트는 스크립트 0, 스타일시트 5.
- 진단서의 "최대 6개"는 스타일시트 5 + noModule 1로 맞아떨어진다(**추정**). 즉 async를 무시하고 noModule을 동기로 세었다.
- 진단서 권고 "defer/async 부착"은 Next.js가 이미 하고 있어 **실행해도 바뀌는 게 없다**.

**진단서가 못 짚은 진짜 문제** — 외부 스타일시트 2개:

| 파일 | 줄 | 내용 |
|---|---|---|
| `app/layout.tsx` | 55-58 | `https://fonts.googleapis.com/css2?family=DM+Serif+Display…` |
| `app/layout.tsx` | 59-62 | `https://cdn.jsdelivr.net/gh/orioncactus/pretendard/…/pretendardvariable-dynamic-subset.css` |
| `app/globals.css` | 86-89 | `--f-display`(DM Serif Display)·`--f-body`/`--f-heading`(Pretendard) 변수 정의 |
| `app/globals.css` / `public/fonts/` | 5-7 | 리디바탕은 이미 자체 호스팅(`RIDIBatang.woff2`) — 같은 방식으로 나머지 둘도 옮기면 된다 |

이 둘은 첫 화면을 그리기 전에 **타사 도메인 2곳의 DNS·TLS 연결을 기다리게** 하고, 그 서버가 느리거나 죽으면 글자가 늦게 뜬다. 자체 호스팅으로 옮기면 외부 의존 0. 효과 크기는 실측하지 않았음(**추정**: 모바일에서 수십~수백 ms).

### 8. URL 대문자·길이 — 대문자는 거짓, 길이는 무의미
| 항목 | 실측 |
|---|---|
| 50편 slug 디코딩 글자 수 | 22 ~ 60자 |
| 인코딩 후 길이 | 142 ~ 452자 (한글 1자 = `%XX%XX%XX` 9자) |
| 디코딩 slug에 영문 대문자 있는 글 | **1편** — `…치조골-이식술-GBR` (의학 약어) |
| 나머지 49편의 "대문자" | 퍼센트 인코딩 16진수 A~F뿐 |

- RFC 3986 §2.1: 퍼센트 인코딩의 16진수는 **대문자 사용을 권장**하며(§6.2.2.1: 정규화 시 대문자로 통일) 브라우저·`encodeURIComponent`가 모두 대문자를 낸다. 소문자로 바꾸는 것은 규격 역행.
- 길이: 사이트맵 규격 상한 2,048자 안이고, canonical·sitemap 모두 같은 인코딩을 씀(`app/blog/[slug]/page.tsx:34`, `app/sitemap.ts:37`). 검색엔진은 한글로 풀어 보여준다(일반 지식).
- 참고 사실 하나: slug는 **09-10 재작성 전 네이버 원제목**에서 만든 것이라 지금 제목과 다르다(50편 중 42편). 검색엔진 관점에서 문제는 아니지만, "새 글" 규칙을 정할 때는 짧은 slug로 가는 게 맞다(D절 갈림길 1).

### 위험
- 1단계: `PageHeader.module.css`나 전역 CSS가 `h1` 요소 선택자로 머리띠를 꾸미면 태그를 바꾼 블로그 글만 스타일이 빠진다 — 0단계 grep으로 먼저 확인. 다른 페이지는 기본값 h1이라 회귀 없음.
- 8단계: `next/font/google`은 빌드 시 구글 서버 접근이 필요(Vercel은 가능, 로컬 오프라인 빌드는 실패). Pretendard dynamic subset은 woff2 100여 개가 저장소에 들어간다(용량 추정 수 MB) — 커밋 전 `git add`는 명시 경로만. 폰트 폴백 순서가 바뀌면 첫 렌더 글꼴 깜빡임 양상이 달라질 수 있어 배포 후 육안 확인 필수.
- 7단계: description은 검색 결과·AI 요약에 그대로 인용된다 — 본문에 없는 효과·기간·가격을 넣지 않는다.
